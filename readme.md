## A web based application for a conference by <a href="https://github.com/naranbhusal02">Narayan Bhusal</a> submitting in <a href="https://macondo.hackclub.com">Macondo</a>

## This application serves information and demonstration of conference details, its theme, motto and other required details.

This web-based app integrated multiple pages in a single website like glimpses, organizers and many more.

**_ The homepage has a navbar with links to other pages like organizer, glimpses and other as well like shown below: _**

# Its features:

├── Provides event theme, motto and benefits
├── Provides glimpses of previous conferences
├── Provide list of different organizing teams and their members
